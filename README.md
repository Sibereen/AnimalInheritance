
# Animal Inheritance Project

## Project Description

This project demonstrates Object-Oriented Programming (OOP) concepts in Java through an animal inheritance hierarchy.

## Classes

- Animal
- Mammal
- Bird
- Fish
- Dog
- Blowfish
- Pigeon

## Interfaces

- AnimalBehavior
- AnimalMove
- AnimalName

## OOP Concepts

- Inheritance
- Polymorphism
- Encapsulation
- Abstraction
- Method Overriding
- Interfaces

## Requirements

- Java JDK
- IntelliJ IDEA

## How to Run

1. Open the project in IntelliJ IDEA.
2. Navigate to `src/animals/Main.java`.
3. Run the `Main` class.
4. View the output in the Run console.
